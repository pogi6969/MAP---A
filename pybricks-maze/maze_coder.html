SPIKE Maze Coder

Pybricks code for SPIKE Prime: from a track map, from calibration, or from your left/right choices.

Robot setup (used by all 3 generators)

Upload a track map

Red = wall, green = shortest path, S = start, G = goal. A sample maze is loaded; upload your own photo or drawing (crop it to the maze edges first).

Path

Click a turn to switch it between 90° and 45°.

What the code does

  1. Drives each straight part by cells, centred between walls (side sensors), braking with v² = 2·a·d.
  2. Stops exactly at the front-stop distance when a wall is ahead.
  3. At each turn it checks the side sensor: if the map's side is blocked it takes the open side. No scanning.

Teach & replay

    
    
      
  1. First run (teach): the robot drives until a wall is in front, reads left and right. If only one side is open it turns there by itself. If both are open it stops and waits for you: press left or right on the hub. Hold the button over 0.7 s for a 45° turn.
    2. 
      
  2. Each choice is saved in the hub. At the goal press the Bluetooth button to finish.
    3. 
      
  3. Next runs (replay): no waiting and no scanning. At each wall it uses the saved choice; if the saved side reads blocked it takes the open side.
    4. 
      
  4. Hold left while starting the program to teach again.
